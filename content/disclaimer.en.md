## Intended use

LocalGen is intended for local gameplay, offline experimentation, education, and bot development. Using it does not grant access, privileges, or status on the official generals.io platform.

Local matches and the bot simulator do not depend on the official game backend. Map Creator offers an optional public-map import that requests the generals.io map API. This feature does not imply game-server integration or official cooperation. Follow the applicable terms when using the official platform or its public services.

## Getting support

Report LocalGen bugs and feature requests to [LocalGen Issues](https://github.com/SZXC-WG/LocalGen-new/issues), where the project community can help. Official generals.io support does not handle LocalGen questions.
