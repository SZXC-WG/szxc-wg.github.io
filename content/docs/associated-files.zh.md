制作或分享新地图时，使用 **`.lgmp`** 即可。它是 v6 的原生地图格式，能保留地形和地图信息，并直接用于本地对局与模拟器。

## 文件支持一览

| 文件 | 用途 | 当前 v6 支持 |
| --- | --- | --- |
| `.lgmp` | v6 原生地图 | 编辑器可读写；本地对局和模拟器可读取 |
| `.lg` | v5 地图 | 编辑器可读写；本地对局不直接列出 |
| 官方 `.json` | generals.io 地图交换 | 编辑器可导入，不能导出或直接开局 |
| `.lgr` | 普通回放 | 格式名称已预留，尚不能加载或保存 |
| `.lgra` | 高级回放 | 格式名称已预留，尚不能加载或保存 |
| `settings.lgsts` | v5 设置 | 旧版本参考 |
| `settings.json` | v6 设置文件名 | 文档中已约定，当前应用尚不保存设置 |

## 地图应该放在哪里

将有效 `.lgmp` 放进 `LocalGen-new` 可执行文件旁的 `maps/` 目录，再重新打开本地对局窗口。程序会扫描这个目录，优先显示地图标题；标题为空时使用文件名，重名时附上文件名。

Windows 和 Linux 便携目录通常直接包含可执行文件与 `maps/`。macOS 的对应位置在应用包内：`LocalGen-new.app/Contents/MacOS/maps/`。

模拟器的 `--map PATH` 可以读取你指定位置的 `.lgmp`，不要求放入这个目录。

## 转换旧地图

在[地图编辑器]({{< relref "docs/map-creator" >}})中打开 `.lg` 或官方地图 `.json`，检查地形，补充标题与作者，再另存为 `.lgmp`。

旧版 `.lg` 只保存棋盘编码。编辑器打开它时会生成标题和创建时间；再次保存为 `.lg` 会丢弃 v6 元数据。官方 JSON 需要有效的 `width`、`height`、`map`、`title` 和 ISO-8601 `created_at`，作者与描述可选。编辑器也能联网按名称导入同类公开地图。

## `.lgmp` 里有什么

`.lgmp` 使用 Qt 数据流二进制格式，不能当作 JSON 编辑。文件包含格式标识、标题、作者、创建日期时间、描述、宽高，以及压缩后的格子记录。每个格子记录包括类型、全局可见的“点亮”状态，以及兵力或出生队伍标记。

编辑器支持宽高各为 1–100 的地图。地图能被打开，并不一定能容纳任意数量的玩家：开局时还要有足够的出生点或零兵力空白平地。

项目中的[关联文件参考](https://github.com/SZXC-WG/LocalGen-new/blob/master/docs/associated-files.md)也列出了回放与设置文件的约定名称。当前可实际使用的是地图文件；菜单中的 **Load Replay** 仍显示尚未实现。
