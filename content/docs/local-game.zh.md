打开 **Local Game**，先用 20×20 的 `Standard` 地图、速度 1 和两名玩家开始。让 P1 保持 `Human`，给另一位玩家选择一个 Bot，然后点击 **Start Game**。

## 调整对局

| 设置 | 如何使用 |
| --- | --- |
| Game Speed | 范围 1–1000；速度 1 约每秒推进一个完整回合 |
| Show analysis | 显示实时兵力与领地图表 |
| Game Map | `Standard` 每次生成随机地图；其他条目来自本地 `.lgmp` 文件 |
| 地图尺寸 | 随机地图宽高各为 1–100，默认 20×20；自定义地图使用文件中的尺寸 |
| 玩家数量 | 2–16；只有 P1 可以选择 `Human`，每个位置都可以选择 Bot |

想观察 Bot 的策略，可以把 P1 也改成 Bot，观看一场自动对战。目前本地对局最多支持一位人类，所有玩家各自为战；设置界面不提供组队。**Enable sounds** 暂时禁用。

速度设置对应每个半回合 `500 / speed` 毫秒的目标间隔。Bot 计算需要时间，因此实际速度也会受到地图大小、对手和设备性能影响。

## 移动你的兵力

单击自己的格子，再按方向键或 `W A S D`，即可沿相邻格子排队移动。普通移动会在起点留下一兵；按 `Z` 后的下一次移动使用一半兵力。山脉、瞭望塔和天文台无法通行。

连续按键可以提前规划路线。若排队动作执行时已经不合法，游戏会跳过该动作。

| 快捷键 | 操作 |
| --- | --- |
| 方向键 / `W A S D` | 移动焦点，并加入一次普通移动 |
| `I J K L` | 只移动焦点 |
| Shift + 方向键 / WASD | 只移动焦点 |
| `Z` | 下一次排队移动使用一半兵力 |
| `Q` | 清空移动队列 |
| `E` | 撤销最后一次排队动作，并返回它的起点 |
| 空格 | 取消格子焦点 |
| `H` | 选中自己的将军 |
| `G` | 选中自己的将军，并将视角移到那里 |
| Escape | 打开投降确认 |

## 看清地图

| 操作 | 效果 |
| --- | --- |
| 按住左键拖动 | 平移棋盘 |
| 鼠标滚轮 | 围绕鼠标位置缩放 |
| 触控板滚动 | 平移棋盘 |
| 双指捏合 | 缩放 |
| `9` / `0` | 缩小 / 放大 |
| `C` | 让整张地图适配窗口并居中 |

按 Enter 可以进入聊天输入框，再按 Enter 发送非空内容。输入框仅在人类参与时显示；旁边的消息面板也会记录系统提示、占领、投降和胜者。这是当前本地对局的消息面板。

## 读懂战况

回合标签末尾的点用于区分半回合阶段。排行榜显示各位玩家的兵力和领地；单击排行榜可以收起或展开名称。被淘汰的玩家会显示遮罩，有击杀的玩家带有骷髅图标。

如果勾选了 **Show analysis**，可以在兵力、领地以及线性、对数坐标之间切换。人类被淘汰后会看到完整地图，可以继续观察；比赛结束后也会显示全图，并停止移动输入。

## 自定义地图无法开始

对局需要一张有效且非空的地图，以及足够分配给所有玩家的出生点或零兵力空白平地。遇到出生点不足的提示时，可以减少玩家数量，或到[地图编辑器]({{< relref "docs/map-creator" >}})补上出生点。

新增地图请使用 `.lgmp`，放入可执行文件旁的 `maps/` 目录，再重新打开本地对局窗口。
