无论你是第一次提问，还是长期参与维护，都应在 LocalGen 社区受到尊重。下面是项目行为准则的中文说明；完整文本见 [GitHub 上的 Code of Conduct](https://github.com/SZXC-WG/LocalGen-new/blob/master/CODE_OF_CONDUCT.md)。

## 我们的承诺

成员、贡献者和维护者共同承诺营造免于骚扰的协作环境。不论年龄、身材、显性或隐性残障、族裔、性征、性别认同与表达、经验、教育、社会经济背景、国籍、外貌、种族、宗教或性取向，每位参与者都应得到平等对待。

我们希望这个社区开放、友好、多元、包容，并能持续健康地发展。

## 交流时的共同约定

- 以理解和善意对待他人，尊重不同的观点与经历。
- 提供有建设性的反馈，也认真听取他人的建议。
- 为自己的错误负责，向受影响的人道歉，并从中学习。
- 讨论决定时，考虑整个社区的利益。

项目不接受带有性暗示的语言、图像或不受欢迎的示好；不接受挑衅、侮辱、人身或政治攻击，以及公开或私下骚扰。未经明确允许，不得公开他人的住址、邮箱等私人信息。其他在专业协作中明显不恰当的行为也在此范围内。

## 适用范围与处理责任

准则适用于项目的所有社区空间，也适用于代表社区的公共活动，例如使用官方邮箱、通过官方社交账号发言，或作为指定代表参与线上线下活动。

社区管理者负责解释和执行这些标准，可以删除、编辑或拒绝不符合准则的评论、代码、提交、Issue、Wiki 编辑等内容，并在适当时说明处理原因。

## 遇到问题时

如遇骚扰、辱骂或其他不可接受行为，请联系 **`lzhang0903@outlook.com`**。社区管理者会及时、公正地审查和调查，并有责任尊重举报者的隐私与安全。

## 违规处理

管理者会根据行为影响采取相应措施：

| 等级 | 适用情况 | 处理方式 |
| --- | --- | --- |
| 纠正 | 不专业、不受欢迎的语言或行为 | 私下书面提醒，解释问题；可能要求公开道歉 |
| 警告 | 单次或一系列违规行为 | 正式警告，在指定期限内停止与相关人员互动，包括站外渠道；再次违反可能被封禁 |
| 临时封禁 | 严重或持续的不当行为 | 指定期限内禁止与社区及相关人员公开或私下互动；再次违反可能永久封禁 |
| 永久封禁 | 持续严重违规、骚扰个人或攻击某类群体 | 永久禁止参与社区的公共互动 |

## 来源
