在主菜单选择 **Create Map**，就能从一张 10×10 的空白地图开始。画好地形、安排出生点，保存为 `.lgmp`，便可以用于本地对局和 Bot 评测。

## 画出棋盘

宽度和高度滑块各支持 1–100。调整尺寸时，原地图与新地图重叠的区域会保留。

单击绘制一个格子，按住右键拖动连续绘制。按住左键拖动可以平移棋盘，滚轮缩放，`C` 让整个棋盘适配窗口。方向键上、下可切换到前一个或后一个工具。

## 选择地形和标记

| 工具 | 地图中的效果 |
| --- | --- |
| 山脉 | 无法通行 |
| 瞭望塔 | 无法通行；相邻正兵力最多的一方获得以塔为中心的 5×5 视野 |
| 天文台 | 无法通行；相邻领地向天文台另一侧延伸最多八格直线视野 |
| 沙漠 | 占领后不获得每 25 回合一次的全局兵力增长 |
| 沼泽 | 被占领时通常每回合减少一兵，兵力降到零时失去归属 |
| 出生点 | 将军的起点，可留空灵活分配，或使用 `A`–`Z` 队伍标记 |
| 城市 | 设置初始兵力，范围 -9999–9999，默认 40 |
| 中立军 | 设置 -9999–9999 的中立兵力；设为零会恢复为空白格 |
| 点亮 | 切换格子是否对所有玩家可见 |
| 擦除 | 恢复为空白、未点亮的格子 |

为每名预期玩家留一个出生点，可以更清楚地表达地图设计。没有足够出生点时，游戏会尝试从零兵力空白平地中补足。

出生点的字母参与出生分组分配，但当前本地对局仍为自由混战，不能通过这些字母在设置界面创建盟友队伍。

## 给地图起个名字

在可折叠侧栏中填写标题、作者、创建日期时间和纯文本描述。保存为 `.lgmp` 后，这些信息会随文件一起保留。

本地对局优先显示地图标题，并去除两端空白。没有标题时显示文件名；标题重复时会附上文件名，方便区分。

## 打开已有地图

编辑器可以打开三种文件：

| 格式 | 使用方式 |
| --- | --- |
| `.lgmp` | v6 原生地图，可读写地形与元数据 |
| `.lg` | v5 旧地图，可读写地形；不保存 v6 元数据 |
| 官方 `.json` | generals.io 地图，可导入后另存为 `.lgmp` |

**Import** 按钮还可以按准确标题获取 generals.io 的公开地图，这一步需要联网。导入后，请保存一份本地 `.lgmp`，再用于离线对局。

JSON 导入会检查宽高、格子数量、标题和 ISO-8601 格式的 `created_at`。无法识别的地形代码会标记为错误格子，保存前可以自行修正。

## 保存并使用

保存时可选 `.lgmp` 或 `.lg`，不能导出官方 JSON。推荐使用 `.lgmp`；保存为 `.lg` 时，编辑器会提醒标题、作者、时间和描述不会保留。

将完成的 `.lgmp` 放到 `LocalGen-new` 可执行文件旁的 `maps/` 目录，然后重新打开 **Local Game**。在 macOS 应用包中，该目录位于 `LocalGen-new.app/Contents/MacOS/maps/`。

需要转换旧文件或查看格式细节时，可继续阅读[地图与其他文件]({{< relref "docs/associated-files" >}})。想批量测试地图，可以使用[模拟器]({{< relref "docs/simulator-guide" >}})。
