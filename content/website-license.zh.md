本站与 LocalGen 应用是两个独立的仓库。应用的开源许可证不会自动适用于本站的全部代码、文字或图片。

## 各类材料的许可

| 材料 | 许可或来源说明 |
| --- | --- |
| LocalGen 应用源码 | GPL-3.0-or-later，见[应用源码仓库](https://github.com/SZXC-WG/LocalGen-new)及文件中的声明 |
| 随附 Quicksand 字体 | SIL Open Font License 1.1，许可文本随字体提供 |
| 本站的布局、样式、脚本与文档 | 网站仓库目前未声明统一的仓库级许可证 |
| 项目版本与贡献者信息 | 来自 LocalGen 的 GitHub 项目；链接指向相应来源 |
| `generals.io` 名称、标志及相关资产 | 归各自权利人所有 |

## 想复用本站材料？

请先检查[网站仓库](https://github.com/SZXC-WG/szxc-wg.github.io)和具体文件是否附有许可声明。未提供统一许可证时，请联系仓库维护者确认相应材料的使用许可，不要直接套用应用源码的 GPL 许可。

字体、第三方素材和从其他来源引入的内容，请保留并遵循它们各自的声明。项目与 generals.io 的关系见[免责声明]({{< relref "disclaimer" >}})。
